# Gaussian random-intercept prior oracle, schema v1

Independent dense marginal likelihood for complete, unit-weight observations with one iid mean random intercept. No package implementation code is used. This fixture set and the thresholds below were frozen before any candidate-engine results. Python 3.13.2 (Anaconda), NumPy 2.3.3, SciPy 1.16.2 and mpmath 1.3.0 were used; run with `OPENBLAS_NUM_THREADS=1 /Users/z3437171/miniconda3/bin/python tools/gaussian-ri-prior-validation/verify.py --self-test`. No optimization grid is run by this test.

For residual `r = y - X beta`, `V = tau² Z Z' + diag(exp(2 W gamma))`. `Z` is the indicator matrix of `group`. The objective is `(n log(2 pi) + logdet(V) + r' V^-1 r)/2` plus `(theta[index]-mean)²/(2 sd²) + log(sd sqrt(2 pi))` for each normal prior, and `lambda theta[index]² / 2` for each ridge prior. Ridge has zero mean and no normalization constant; lambda=0 gives exactly the unpenalized objective. No prior is placed on `tau`. `tau=0` is valid because the positive diagonal keeps `V` positive definite. Gaussian prior constants are included, so compare the same full objective and do not silently drop constants.

Each `fixtures/ri_NN.json` is self-contained. `raw_data` and `formula` export the predictors and R-style formula mapping; adapters must verify their model matrices against `X` and `W` before fitting, including the categorical B indicator. `formula.mean_columns` gives semantic labels, which may differ from a package's printed coefficient names. Numeric rows of `X` and `W` are the authoritative model matrices (including explicit intercept, binary/factor contrast, or no intercept as applicable). `group` is zero-based and repeated labels represent the same random intercept. `point.beta` and `point.gamma` follow matrix column order, `point.tau` is the standard deviation (not log or variance). Prior indices are zero-based within `block` (`beta` or `gamma`); `sd` is strictly positive for normal priors; `lam` is nonnegative for ridge. `preflight: true` identifies ri_01 to ri_04; ri_01 and ri_02 have constant residual scale, the others include a scale covariate. Both prior types occur on both coefficient blocks. `expected.nll`, `expected.gradient`, and `expected.hessian` correspond to the complete objective and parameter order beta, gamma, tau. Their values were independently computed at 50 decimal digits with mpmath from a separate marginal likelihood implementation, then rounded to JSON floats; the NumPy/SciPy implementation checks those references. The Hessian under test is a central difference of the analytic gradient, compared to mpmath's numerical high-precision second derivative. `conditional_beta(f)` computes the exact conditional penalized least-squares solution with gamma and tau fixed. It is checked by its independently computed gradient, including beta ridge cases. Normal mean zero with sd=1/sqrt(lambda) and ridge lambda have the same derivatives and differ by the normal density constant; the self-test checks this and lambda=0.

Adapter outputs should preserve `id`, report model-matrix/parameter order and objective convention, convergence and boundary status, and include `point` values and objective. For pointwise comparison expose objective, gradient, and Hessian on the beta/gamma/tau scale; transform derivatives explicitly if fitting in a log-tau parameterization. For fitted comparisons report objective and identified coefficients plus any bounds, optimizer and stopping diagnostics. For log-tau coordinates, the gradient is `tau * dL/dtau`; the tau/tau Hessian entry is `tau² L_tau,tau + tau L_tau`, and a cross entry with another parameter is `tau L_other,tau`. At tau=0 the self-test also compares the unpenalized value directly with the diagonal Gaussian formula, checks zero tau gradient, and checks `L_tau,tau = tr((V^-1 - zz′) K) = 2 dL/d(tau²)` for `K=ZZ′` and `z=V^-1 r`. Central differences extend the even tau² expression to negative tau solely for this derivative check. The boundary fixture permits pointwise tau=0 evaluation; a log-tau optimizer cannot represent that point exactly. Never silently delete failed fits or claim identified-coefficient agreement for unidentified or boundary-affected components.

Normalized componentwise error is `abs(a-b)/(1+max(abs(a),abs(b)))`. Frozen maxima are value `1e-9`, gradient `1e-6`, Hessian `1e-5`, fitted objective `1e-7`, identified coefficient `1e-5`. The last two govern future fit comparisons and are not exercised by self-test. The self-test rejects omitted, doubled, misindexed and altered-constant prior mutations against the stored mpmath objective. `generate_fixtures.py` documents provenance; **do not regenerate references in response to candidate results**. `SHA256SUMS` records the frozen fixture bytes and oracle contract.

Fitted references use profiled beta and optimized scale coefficients/nonnegative group variance. Optimizer success alone is insufficient: eligibility requires finite coordinates and scores and full-model projected first-order conditions within 1e-6. Fitted boundary status is separate from the optimization subproblem. All attempts remain recorded. Independent review confirmed all twelve selected numerical solutions were unchanged by the optimization audit. Finite multistart checks do not establish a global optimum or calibration.

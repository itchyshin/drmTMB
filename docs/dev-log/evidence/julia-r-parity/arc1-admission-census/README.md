# Arc 1 slice S2: the pure-R admission census

`census.tsv` in this directory is a snapshot of `tools/julia-admission-census.R`'s
output, regenerated by `Rscript tools/julia-admission-census.R` from the
repository root. It is evidence, not the check: the actual check is
`tests/testthat/test-julia-admission-census.R`, which recomputes the same
census in process on every run (D-277) and fails if the bridge's admission
behaviour has moved since this file was last regenerated.

## What this measures

For one small formula per `(family, structure, dpar)` cell -- every family in
`drm_julia_family_registry()`, crossed with `{none, (1|g), (1+x|g), phylo,
relmat, spatial, animal, bivariate q2 phylo, bivariate q4 dense phylo,
bivariate q4 block-diagonal phylo}`, crossed with the RE-carrying dpar slot(s)
(`mu`/`mu1`, and `sigma`/`sigma1` when the family has one) -- the tool drives
the REAL top-level `drmTMB(..., engine = "julia")` admission path with every
Julia path/option cleared, so the call can never boot a live Julia process.
`drm_julia_setup()` (R/julia-bridge.R) throws its own "needs a local
DRModels.jl (or legacy DRM.jl) checkout" abort before it ever calls
`JuliaCall::julia_setup()`; recognising that one message is how the tool
tells ADMIT (the call reached the Julia boundary) from REFUSE (an earlier
gate fired). Any other abort is matched against
`drmTMB:::drm_julia_intentional_gates()`'s own `message_pattern` column to
name the gate.

Plus one targeted extra row outside the grid: `truncated_nbinom2` + `hu ~ 1`
(finding 7, row 62's hurdle-NB2 cross-spelling).

## Columns (`census.tsv`, tab-separated, exact pinned header)

`family, structure, dpar, formula, decision, gate_id, ledger_row`

- `decision` is one of `ADMIT`, `REFUSE`, `REFUSE_UNGATED`, `NOT_APPLICABLE`.
- `gate_id` is the matched `julia-gates.tsv` `gate_id` for `REFUSE` rows,
  empty for `ADMIT`/`NOT_APPLICABLE`, and `"UNGATED: <message>"` (the
  offending abort, single-line, truncated to ~300 characters) for
  `REFUSE_UNGATED` rows -- there is no separate message column in the pinned
  header, so an ungated refusal's message lives here.
- `ledger_row` is the `capability_id` from `inst/extdata/julia-capabilities.tsv`
  that covers an `ADMIT` cell, or empty when no row joins (an unledgered
  admit -- the thing Arc 1 plan slice S5 exists to fix). It is resolved by
  calling `tools/write-parity-matrix.R`'s own join functions
  (`pm_tsv_rows_for_family()`, `pm_family_constructor()`, `pm_syntax_calls()`),
  `sys.source()`d at run time, never a second independent matcher.
- `formula` is a human-readable `bf(...)` reconstruction for a real cell, or
  (for `NOT_APPLICABLE` rows) a one-line reason -- there is no separate
  reason column in the pinned header either.

## NOT_APPLICABLE bookkeeping

- A bivariate structure (`bivariate q2/q4 phylo`) on a univariate-only family.
- `structure = "none"` with the sigma-side dpar (there is no RE term to place
  in a "none" structure; only the mu-side plain formula is tested there).
- The sigma-side dpar for a dispersionless family (poisson, binomial,
  cumulative_logit have no `sigma` dpar at all).

## Measured-finding hypotheses this census checks

- **(a)** ordinary `(1 | g)` on poisson/nbinom2/binomial/gamma/beta is
  ADMITTED with no ledger row -- confirmed for all five families.
- **(b)** bivariate q4 block-diagonal phylo is ADMITTED on `biv_gaussian`,
  identically to q4 dense -- confirmed (`drm_julia_biv_phylo_dimension()`
  classifies by the dpar set alone, ignoring the covariance-block tag).
- **(c)** `truncated_nbinom2` + `hu` is ADMITTED in R (finding 7). This
  pure-R census cannot boot Julia to re-verify the "fails inside Julia" half
  of that finding independently; that half stands on finding 7's own
  citation.

## Regenerating

```r
OPENBLAS_NUM_THREADS=1 Rscript tools/julia-admission-census.R
```

Takes a few seconds; writes `census.tsv` (streamed row by row, flushed after
every cell) and `census.log` (a heartbeat line per cell) in this directory.

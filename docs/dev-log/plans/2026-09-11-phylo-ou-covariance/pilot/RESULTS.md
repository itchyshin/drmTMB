# Phylogenetic OU covariance: five-fixture timing pilot

The first five frozen local recovery fixtures form a measured timing pilot. They
used the same estimator, library, seeds, data-generation settings and retained
result rows as the recovery panel; no extra fits were launched.

| Measure | Result |
| --- | ---: |
| Fixtures | 5 / 5 complete |
| Total elapsed time | 3.193 seconds |
| Median elapsed time | 0.240 seconds |
| Maximum elapsed time | 2.144 seconds |
| Positive-definite Hessians | 5 / 5 |

This is a local implementation timing only. It does not authorize, estimate, or
substitute for a remote recovery or calibration campaign.

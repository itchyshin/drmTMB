Reported by Russell Dinnage, independent evaluation of drmTMB 0.7.0 at 945da24f

Supporting working: none cited beyond the reproduction in §4

## What Russell found
`AIC(drm_fit, gls_fit)` returns a bare numeric scalar (no warning, no message) instead of the expected
comparison table; `BIC()` does the same. `AIC(drm1, drm2, gls1)` returns a 2x2 data frame with the
`gls` row silently gone. `AIC(drm1, 42)` swallows the nonsense `42` argument without complaint.
Reversing the argument order — `AIC(gls1, drm1)` — gives the correct 2-row table via
`stats::AIC.default` dispatch, and `AIC(drm1, drm2)` (both drmTMB) is also correct. So the defect is
specific to `AIC.drmTMB` when a foreign fit sits in `...`, and the failing order (new model first) is
the natural one a user reaches for when comparing a new package against an incumbent.

## Where (at 945da24f)
`R/methods.R:2677` (`AIC.drmTMB`).

## Since-audit status on main (4bfb9d721, 2026-09-13)
PRESENT. `AIC.drmTMB` is now at `R/methods.R:2681-2685`:
```r
AIC.drmTMB <- function(object, ..., k = 2) {
  fits <- c(list(object), list(...))
  fits <- fits[vapply(fits, inherits, logical(1L), what = "drmTMB")]
  drm_information_criterion(fits, function(o) k, "AIC")
}
```
`fits[vapply(fits, inherits, ..., what = "drmTMB")]` silently drops any non-`drmTMB` object passed in
`...` with no warning. `drm_information_criterion()` (`R/methods.R:2670-2677`) returns `values[[1L]]` —
a bare scalar — whenever `length(fits) == 1L`, which is exactly what happens once a foreign fit has
been filtered out. `BIC.drmTMB` (`R/methods.R:2689-2694`) shares the identical filtering line and the
same `drm_information_criterion()` helper, so it has the identical defect. `git log --oneline
945da24f..HEAD -- R/methods.R` was checked with `git log -p ... | grep -n "AIC.drmTMB\|drm_information_criterion"`,
which returns no hits — neither function has been touched since the audit commit. No existing-issue
match found (checked "AIC scalar", "AIC(drm" in open-issues.json).

## Proposed fix (Russell's, if stated)
Not stated beyond "small". Warn (or error) when a non-`drmTMB` object in `...` is dropped, rather than
silently filtering it out before the length check that decides scalar-vs-table.

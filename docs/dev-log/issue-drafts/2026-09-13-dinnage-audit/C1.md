TITLE: [Dinnage audit C1] log(sigma) clamp detector is one-armed; check_drm() misreports a 96%-wrong fit
LABELS: audit-dinnage, bug, critical
---
Reported by Russell Dinnage, independent evaluation of drmTMB 0.7.0 at 945da24f
(https://github.com/rdinnager/drmTMB_eval/blob/main/REPORT.md §4, Appendix A row C1; severity critical).
Supporting working: adversarial/atk-invariance-rescaling_verdict.md, adversarial/REPORT-wb-guards.md,
adversarial/C1-VERIFIED-BY-ORCHESTRATOR.md, code-review/JOINT-REVIEW.md

## What Russell found
The `log(sigma)` soft-clamp is two-sided (band `[-12, 12]`), but the detector
`drm_logsigma_clamp_active()` only fires on the upper arm (`values > hi`). Rescaling a response by
1e-6 (e.g. grams to micrograms) pushes all 400 observations below the lower bound; the `sigma:x`
coefficient is then wrong by up to 96.5% (sign flip at smaller scales), yet `check_drm()` prints
*"The log(sigma) clamp is not active at the optimum."* A 2,000-replicate re-run found the silent-wrong
rate (converged, clamp row `ok`, bias > 0.1) is **100.0%** at the triggering scale. `NEWS.md:1462` and
`:1485` both assert the package warns when the clamp is active; the lower arm is not covered by that
claim. The rationale for the asymmetry (meta-analysis `tau -> 0` is legitimate) is itself correct
(confirmed independently, see §5.1) but the fix must make the lower arm a `note`, not silence.

## Since-audit status on main (4bfb9d721, 2026-09-13)

unchanged at `tests/testthat/test-clamp-active-guard.R:33`

`git log --oneline 945da24f..HEAD -- R/drmTMB.R` shows 17 commits touching the file; only
`cb1671cb7 fix(start): detect clamp-saturated starts and refuse REML fixef: starts` is
clamp-adjacent, and it addresses start values, not this detector. No existing-issue match found
(`gh issue list --search "clamp"` returns nothing on point).

## Proposed fix (Russell's, if stated)
Diff supplied in the report: report both arms, return `arm = "lower"|"upper"`, and treat the lower
arm as a `note` (not a warning) so a legitimate `tau -> 0` meta-analysis fit is not warned at.
Invert the test at `tests/testthat/test-clamp-active-guard.R:33` to assert `arm == "lower"` instead
of `expect_null(...)`. Estimated ~15-30 lines together with Md-A and M3.

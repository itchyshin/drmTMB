Reported by Russell Dinnage, independent evaluation of drmTMB 0.7.0 at 945da24f
(https://github.com/rdinnager/drmTMB_eval/blob/main/REPORT.md §4, Appendix A row S2; severity major).

Russell's audit independently confirmed and quantified the exact concern this issue raised:
`summary()$derived`'s repeatability-style row divides by the *median* residual sigma
(`exp(beta0^sigma)`), not by `E[sigma^2]^0.5`, whenever sigma is not constant across observations —
measured error +60.6% at omega = 0.8 (the SD of the random effect on sigma) and +8.51% at omega = 0.4.
The mechanism was proved directly: `residual_sd == exp(beta0^sigma)` to a maximum absolute difference of
0.000e+00 on every replicate. Two existing mitigations: the row carries `conf.status =
"derived_interval_unavailable"` and prints its own ingredients, so a reader who checks whether
`residual_sd == exp(coef sigma:(Intercept))` can discover the convention — but there is no warning about
the convention itself. Related but distinct: #1231 flags the same *family* of scale-convention issue in
`heritability()`'s help text, not in `summary()$derived`.

## Since-audit status on main (4bfb9d721, 2026-09-13)
PRESENT. `drm_derived_summary_rows()` (`R/methods.R:4504-4563`) still computes `sigma <-
drm_constant_residual_sigma(object)` (line 4509) and stores `residual_sd = sigma` per row (line 4552).
`drm_constant_residual_sigma()` (`R/methods.R:4602-4619`) returns `exp(unname(beta[[1L]]))` — the fixed
intercept coefficient on the log link, i.e. the median sigma — with no correction for a random-effect
component on `sigma` (its only guards are: exactly one fixed coefficient named `"(Intercept)"`, a `log`
link, and no known-variance override; none of these detect a random intercept on `sigma`, which is
exactly the omega the report varies). Additional scope note found while re-verifying: this same helper
is now also called from `R/heritability.R:285`, inside the newly-ported `heritability()`/`icc()`/
`repeatability()` family (added by commit `9143eef71`, after 945da24f) — so the median-vs-`E[sigma^2]^0.5`
convention gap is not confined to `summary()$derived`; it is shared by the new accessors too, though
those additionally reject fits with random slopes on `mu`
(`drm_variance_ratio_reject_random_slopes()`, `R/heritability.R:386`) — that guard does not touch
`sigma`. `git log --oneline 945da24f..HEAD -- R/methods.R` shows a `rename:` commit
(`4dbc71653`, "summary() derived rows state their TOTAL-variance denominator") that relabels the
denominator description but does not change the `residual_sd` computation itself.

# Plan versus actual — R5 fixed-alpha OU sensitivity

R5 implemented the planned local sensitivity runner: one BM baseline and five
location-side OU fits with alpha mapped fixed at 0.1, 0.3, 0.7, 1.3, and 2.5.
The same retained tree, 1,536 rows, fixed intercept formula, residual-scale
formula, ML setting, and optimizer were used throughout. All six fits
converged with positive-definite Hessians. The implementation is currently an
evidence runner, not public syntax. The next bounded task is to locate
Ayumi's exact data/tree and repeat the like-for-like receipt before deciding
whether a user-facing helper is warranted.

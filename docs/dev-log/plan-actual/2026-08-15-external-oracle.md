For CI: no repo-level check flags "this PR has zero workflow runs" or "this PR's base branch is non-default"; detection depended entirely on someone running `gh pr checks`/`gh run list` and noticing the absence, and it happened twice in one session for two different workflows before anyone looked. **This distinction matters exactly as posed: both were near-misses that worked out this time because a human-equivalent check happened to run, not because the process makes that outcome the default.** Recommend a structural fix rather than trusting the next session's vigilance (see below).

## Process fixes worth promoting

1. **(Highest priority) A pre-merge PR-CI-existence check.** Add a lightweight repo check (a `workflow_dispatch`-triggerable script, or a required branch-protection status check) that fails/warns when a PR has zero associated workflow runs, or when a PR's base branch is not the default branch. This plan's own execution hit this exact failure mode twice in one session, in two unrelated workflows (`pkgdown.yaml`'s `workflow_run`-only trigger, and `R-CMD-check.yaml`'s `branches: [main, master]` filter on `pull_request`), and both times it was caught only by someone manually reading `gh pr checks`/`gh run list`. A recurring failure mode caught by luck twice in a row is exactly the pattern worth converting into a gate.

2. **A worktree-scoping guard for dispatched agents.** The primary-checkout write (Curie/S3) was caught this time, but nothing structural prevents a sub-agent from writing outside its assigned worktree. A cheap preflight/postflight (compare the working directory of each `Write`/`Edit` call against the intended worktree root, or a lint step before consolidation) would close this without relying on the orchestrator noticing.

3. **Record routing corrections where they happen.** When a plan's named agent type is swapped for a different one mid-execution (as with S2/S4/S5/S7 here), leave one line in the check-log or commit message naming the swap and why. This costs nothing and would have made Drift #2 and #5 visible without a full reconciliation pass.

# After Task: model.frame() for a drmTMB fit

## Goal

Stop `model.frame(fit)` from returning the internal TMB specification, and
return the location rows used to fit, with the location formula's `terms`
attribute.

## Implemented

`model.frame.drmTMB()` returns `fit$model$model_frame$mu`, the data frame
`stats::model.frame()` built for the location formula at fit time. That frame
already carries the `terms` attribute. `terms.drmTMB()` returns it.
`model.matrix.drmTMB()` rebuilds the dense location design from it.
`fit$model` is only read.

If the location frame was dropped (`keep_model_frame = FALSE`), the method
stops and tells the user to refit with `keep_model_frame = TRUE`. If the fit
has `mu1` and `mu2` instead of `mu`, the method stops and names the stored
frames. `model.frame.drmTMB_julia()` stops for the same reason the bridge
cannot honestly rebuild the frame: class `drmTMB_julia` stores training data
and the formula, not a location model frame, and missing-row and structured-row
rules are route-specific.

## Mathematical Contract

No likelihood, link, or formula-grammar change. The returned frame is the
location design's row set. Under the default complete-case policy its row
count equals `nobs()`. When missing responses are retained, the stored frame
includes those rows and `nobs()` still counts observed likelihood rows.

## Team Learning

`stats::model.frame.default` returns `$model` only when the generic is called
with one argument. A method whose first formal is not `formula` does not
receive that argument, because the generic's formal name is `formula`.

## Known Limitations

The location frame does not include covariates that appear only on `sigma`,
`nu`, or another distributional formula. Bivariate `mu1` / `mu2` is not
combined. Julia-engine fits do not grow a reconstructed frame in this change.
`model.matrix()` returns a dense matrix even when the fitted `mu` design was
stored sparse.

## Next Actions

A later change can choose one bivariate contract: return `mu1` only, add a
`dpar` argument, or define a row alignment and a single `terms` object for a
combined frame. A Julia frame needs either a frame stored at bridge time or an
explicit rebuild that repeats the bridge's row rules.

## What Did Not Go Smoothly

The first ledger draft used several shorthand evidence references that were
understandable to the author but not independently auditable. Luna rejected
them. The GitHub connector then returned HTTP 403 for issue comments despite
working read access; the successful fallback was authenticated `gh` with each
verified body supplied through a file, avoiding shell interpolation.

## Team Learning

An issue sweep needs both semantic and mechanical verification. Semantic
review stabilized the blocker logic, while a separate path-and-count verifier
caught citation and summary defects that did not change the conclusion but
would have weakened the durable record. Mutation receipts belong in the same
ledger as the proposed actions.

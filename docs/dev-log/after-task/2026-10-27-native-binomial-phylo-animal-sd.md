# After Task: Native Binomial phylogenetic and animal SD pair

## 1. Goal

Add one native Binomial q1 intercept pair with separate predictor-dependent SD formulas under logit, probit, and complementary-log-log links: a tree-backed phylogenetic field and an animal field using covariance matrix A.

## 2. Implemented

The current Binomial builder admits the phylogenetic plus animal q1 intercept pair. A fixed-seed synthetic test fits the pair under logit, probit, and complementary-log-log links and checks target-specific outputs. No likelihood code was changed in this slice.

## 3a. Decisions and Rejected Alternatives

The scope stays at independent q1 intercept fields with a phylo tree and animal A covariance. This slice does not add correlated blocks, other provider combinations, or new likelihood code.

## 3. Mathematical Contract

The linear predictor is `eta = X beta + tau_tree[g] u_tree[g] + tau_animal[h] u_animal[h]`. The two latent fields are independent and use their supplied covariance kernels. Each log SD has its own fixed-predictor design. The predictors are constant at their respective latent groups. Animal covariance labels are reversed relative to the data factor levels to check name alignment.

## Goal

Let a cumulative-logit model carry a fixed-effect scale formula with an
explicit identifiability contract, without changing any existing fit.
`corpair(~x)` (#531) and the multinomial response (#969) stay deferred and
were not touched.

## Model and identifiability contract

```text
Pr(y_i <= k) = logit^{-1}(disc_i * (theta_k - mu_i))
log(disc_i)  = Z[i, ] gamma            (intercept fixed at 0)
```

```r
drmTMB(bf(score ~ x, disc ~ z), family = cumulative_logit(), data = dat)
```

The `disc` intercept is fixed at `log(disc) = 0`. For any `c > 0`, scaling the
cutpoints and location coefficients by `c` and `disc` by `1 / c` leaves every
category probability unchanged, so one scale direction must be pinned. This is
the constraint used by `ordinal::clm(scale = ~ z)`; clm models the latent scale
`s = 1 / disc`, so its `zeta` equals `-gamma`. `disc ~ 0 + z` is rejected with
an error that says why; random effects, structured terms, and offsets in
`disc` are rejected. `sigma(fit)` returns the latent scale `1 / disc` for
fits with a `disc` formula and stays `1` otherwise. The contract is stated in
`?cumulative_logit` (new "Identifiability of `disc`" section) and in
`docs/design/03-likelihoods.md`.

## Files changed

- `R/parse-formula.R`: `disc` is a known distributional parameter, so
  `disc ~ z` parses as a parameter formula rather than a second response.
- `R/drmTMB.R`: `drm_build_cumulative_logit_spec()` accepts `disc`; new
  `ordinal_disc_formula()` / `ordinal_disc_design()`; map, TMB data, and
  coefficient split carry the `disc` block. `disc ~ 1` leaves the spec
  untouched.
- `src/drmTMB.cpp`: model_type 13 multiplies each cutpoint contrast by
  `disc_i = exp(X_sigma * beta_sigma)`; with the 1x1 dummy `X_sigma` the

  stay clear of the open PRs (#1514, #1507, #1509) and the mi() blocks
  (#1513).

  category probabilities, and `sigma()`.

## Tests of the tests

- Exact equality: `disc ~ 1` against no `disc` formula with
  `expect_identical()` on `opt$par`, the objective, `cov.fixed`, fitted values,
  and `df`; a stray `exp(0)` rounding or an extra free parameter would fail.
- Recovery: n = 3000, `gamma = 0.45`, four categories; estimates within 4 SE
  and the Wald interval for `gamma` covers the truth.
- External comparator: continuous and factor `z` against `ordinal::clm`
  (logLik 1e-6, coefficients 1e-4, SE 1e-3). The factor case pins the
  treatment-contrast column name (`gb`).
- Independent probability reconstruction: logLik, fitted scores, category
  probabilities, newdata probabilities, and `fitted_distribution()` d/p/q are
  rebuilt by hand from `plogis(disc * (theta - eta))`.

## What did not go smoothly

`bf()` silently parsed `disc ~ z` as a second response; the parser's known-dpar
list had to learn `disc`. Any user data with a response column literally named
`disc` will now be read as a parameter formula; no test, vignette, or example
in the repository uses such a name.

## Known limitations and next actions

- Fixed effects only in `disc`; no random effects, structured terms, or
  offsets. `mu` random effects and the phylo intercept combine with `disc`
  (a `(1 | id)` combination is smoke-tested, not recovery-tested).
- No interval-coverage study for `gamma`; Wald intervals are reported with the
  same status as other cumulative-logit fixed effects.
- Julia bridge: refused until DRM.jl has a discrimination submodel and a
  parity receipt.

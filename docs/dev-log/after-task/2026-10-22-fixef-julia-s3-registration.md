# After Task: fixed-effect extraction dispatch in fresh R processes

## 1. Goal

Make the exported `fixef()` generic dispatch to drmTMB's native and Julia fit methods after a clean namespace load, including child processes used by live bridge tests.

## 2. Implemented

The `fixef` methods for `drmTMB`, `drmTMB_julia`, and `drmTMB_julia_xfam` now register explicitly against `nlme::fixef`. Roxygen generated the qualified S3 method entries in `NAMESPACE`. A fresh-process regression test covers all three fit classes and confirms that the existing native `ranef()` method still dispatches.

## 3. Mathematical Contract

No likelihood or coefficient parameterization changed. `fixef()` continues to return the same fixed-effect coefficient blocks as `coef()`; this change makes the documented extractor dispatch available in a fresh R process.

## 3a. Decisions and Rejected Alternatives

The method body was already present. Replacing calls to `fixef()` with `coef()` in the failing missing-data test would have hidden the public dispatch defect, so the method registration was corrected and tested instead.

## 4. Files Touched

- `R/methods.R` and `R/julia-bridge.R` use qualified `nlme::fixef` S3 registration.
- `NAMESPACE` was regenerated by roxygen2.
- `tests/testthat/test-fixef-imported-generic-dispatch.R` checks all three fit classes in a fresh R child.
- `man/predict.drmTMB_julia.Rd`, `man/summary.drmTMB_julia_xfam.Rd`, and `man/rho_latent.Rd` were refreshed by the package-wide documentation run.
- `.unlazy/general-sd-regression/GATES.md`, `docs/dev-log/check-log.md`, and this report record the limited G4 evidence.

## 5. Checks Run

- The new fresh-child regression failed before the change with `UseMethod("fixef")` and no method for `drmTMB_julia`.
- `devtools::document()` completed and generated `S3method(nlme::fixef, ...)` entries for all three classes.
- The regression passed for native, Julia, and legacy cross-family `fixef()` classes, and for native `ranef()` dispatch.
- Adjacent filter `julia-(missing|marker-slope-guard|fe-only-fence|structured)` passed with exit code 0 and five live Julia tests. Three tests were skipped because their generic fixtures are not available. One existing TMB marker-slope warning reported `NaNs produced`.
- The initial sandboxed adjacent run was blocked by JuliaCall's `~/.julia` cache pidfile permission. The rerun with standard cache access passed.
- `pkgdown::check_pkgdown()` passed with no problems; it reported the existing Pandoc `--mathml` deprecation warnings.
- Full package check has not yet run.

## 6. Tests of the Tests

The regression launches a clean R child, loads this candidate with `pkgload`, constructs representative objects for each class, and calls the public `drmTMB::fixef()` generic. It failed before the registration change and passed after it, so it covers the isolated dispatch boundary that failed in the live missing-data test. It also calls `drmTMB::ranef()` on a minimal native fit object to verify that this neighbouring imported generic continues to dispatch.

## 7a. Issue Ledger

A read-only open-issue search for `fixef Julia method` found no matching issue. No issue was opened, commented on, or closed.

## 8. Consistency Audit

The three documented S3 methods now register against the same imported `nlme::fixef` generic that `drmTMB` re-exports. Their implementations still delegate to the existing `coef` methods. The failure in the adjacent missing-data test is resolved without changing model fitting.

## 9. What Did Not Go Smoothly

The first combined run stopped at the sandbox's JuliaCall cache write. After allowing the normal cache access, that run exposed the actual `fixef()` dispatch failure in a fresh child process. The isolated child test then confirmed the failure before the code change.

## 11. Team Learning

For S3 methods on an imported generic, test dispatch from a fresh namespace in a new process. In-process tests can pass when a method is already registered in the parent process.

## 10. Known Residuals

This change verifies fixed-effect extraction dispatch for three drmTMB fit classes and native `ranef()` dispatch only. It does not verify other imported S3 generics, all output methods, simulation/refit semantics, or interval calibration. The adjacent filter retains one NaN warning and three documented skips. Programme gates G0, G1, G3, G4, G6, G7, and G8 remain open; G5 calibration is deferred.

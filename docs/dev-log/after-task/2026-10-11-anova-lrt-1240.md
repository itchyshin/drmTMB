# After-task: anova.drmTMB likelihood-ratio table (#1240)

**Reader:** maintainers and users coming from lme4/glmmTMB.

**Root cause.** `anova.drmTMB()` ended in an unconditional `cli_abort()` even
though `drm_lrtest()` (oracle-tested against DRM.jl) already existed.

**Change.** Per the owner decision on #1240 (11 Oct 2026), `anova.drmTMB()`
runs sequential `drm_lrtest()` comparisons and returns an `anova` data frame.
REML-different-mean and MAP guards come from `drm_lrtest()`. When the larger
fit adds exactly one or two random-effect SDs (and df matches), the p-value is
the chi-bar-square value from `lrt_boundary()` with a
`drmTMB_anova_boundary_warning`; other boundary cases keep the chi-square
p-value and the existing conservative-p warning.

**Not changed.** `anova()` on `engine = "julia"` fits still refuses (its test
is kept). `update()` and other #1117 items stay on that umbrella. Rd files were
edited by hand to match roxygen (roxygen2 not available in this sandbox).

**Tests.** `tests/testthat/test-anova-drmtmb.R` (14 expectations); old
refusal test for native fits removed from `test-model-comparison.R`.

Addresses #1240.

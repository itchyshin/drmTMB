## What changed

1. `R/drmTMB.R` (coefficient-model gate, `out$has_sd_phylo_coef_model`): the gate required only one mapped row per coefficient (`colSums(map >= 0) > 0`). It now requires `nrow == length(spec$y)` and every entry `>= 0`, the same invariant as the Binomial gate. The builder already maps every observation, so no live fit changes; the check removes the silent unit-scale axis a future provider with a different SD group would produce.
2. `tests/testthat/test-gamma-animal-q2-correlated-sd.R`: two new `test_that` blocks appended, no existing assertion touched.
   - Raw non-unit-diagonal `A` (`D A0 D`, diagonal range about 0.36 to 3.2, passed in shuffled order). The R joint oracle agrees with the TMB joint objective at 1e-6, and the oracle with `cov2cor(A)` differs by more than 1e-3. The latent nodes follow the rows of the supplied `A` and observations map by name, so the oracle indexes nodes in the shuffled `A` order. My first version indexed them in data-level order and disagreed by 1384; that was a mistake in the test, fixed before any tolerance was touched.
   - `log_sd_phylo` is not among `fit$obj$par` (mapped off) and `beta_sd_mu` is, for the labelled and unlabelled fits.
3. `docs/design/03-likelihoods.md` (Gamma labelled q2 paragraph) and `docs/design/18-random-effect-scale-models.md` (row for Gamma labelled q2): the "no oracle" wording is replaced by the oracle evidence, and the limits are stated.

## 11. Team learning

**A gate is only as true as the artifact it names.** Every platform result here was genuine; the failure
was that the one machine-checkable record pointed at a superseded tarball and returned green. Evidence
and the gate that guards it drift apart silently, because nothing fails when they do — the gate keeps
passing, more confidently than ever, about the wrong thing. Re-point the gate as part of the freeze, not
as a later cleanup.

**"Same commit" is not "same bytes."** GitHub Actions and R-hub check out source and build their own
tarball; they never see the frozen file. `RUNG-REPORT` said "applies to this candidate"; `cran-comments`
upgraded that to "run against these exact bytes". One word of drift turned a careful claim into a false
one, in the document a CRAN volunteer reads. Keep the two classes labelled separately.

**Frozen bytes are perishable.** `R CMD build` embeds timestamps, so a rebuild from the same commit
produces a different file that no existing platform result describes. The candidate had one volatile
copy in `/private/tmp`. Freeze durably, immediately.

# After-task report: batch 32, native Binomial labelled q2 SD blocks (animal and phylo)

Date: 2026-11-02. Reader: Shinichi, and the next agent on the general-sd-regression lane.

## 1. Goal

Batch 31 found that native drmTMB refuses the labelled `(1 + x | p | id)` form for
Binomial `animal()` and `phylo()`, so the correlated-block rows for those routes could
not be met. Find out why, and admit the routes if the refusal is not a real gap:
Binomial `animal(1 + x | p | id, A = A)` (logit, probit, cloglog) and
`phylo(1 + x | p | id, tree = tree)` (logit), each with one SD formula for `mu:I` and
one for `mu:x1`.

## 2. Implemented

Why it was refused: two reasons. (a) R side: `validate_binomial_structured_mu_term()`
aborted on any `covariance_label` (`R/drmTMB.R`, the "unlabelled q1" message), the
Binomial q2 base gates required `is.null(covariance_label)`, `make_tmb_data()` only set
`has_sd_phylo_coef_model` for unlabelled Binomial terms, and `eta_cor_phylo` /
`has_phylo_mu_q2_covariance` / `corpars` were wired for NB2, Poisson, Gaussian and Gamma
only. (b) C++: the Binomial branch (`model_type == 18`) of `src/drmTMB.cpp` had only the
independent-field prior (one unit-scale `N(0, K)` per coefficient); it had no correlated
q2 prior. So this is new C++.

New C++, stated explicitly: the Binomial branch now has the labelled q2 prior, a direct
copy of the NB2 block (`has_phylo_mu_q2_covariance == 1`, SD-formula case): unit-scale
fields `N(0, R kron K)` with `rho = 0.999999 tanh(eta_cor_phylo)`, quadratic
`(q11 - 2 rho q12 + q22) / (1 - rho^2)`, log-determinant `n log(1 - rho^2)`. The
Binomial likelihood and the per-row coefficient SD scaling were already there and are
unchanged. The branch errors if reached without two coefficient SD formulas. The
unlabelled path is the `else` of the new `if`, byte for byte.

R:

- `R/binomial-q2-sd.R` (new): `drm_binomial_labelled_q2_ok()`, true only for a labelled
  `animal` term (A, Ainv or pedigree; any link) or labelled `phylo` term (logit), with
  intercept plus one slope and exactly two SD formulas.
- `R/drmTMB.R` (19 changed lines): the animal and phylo Binomial q2 base gates accept
  a label when that predicate holds; `validate_binomial_structured_mu_term()` gets
  `allow_labelled_q2`; `make_tmb_data()` admits the labelled phylo term via the existing
  `phylo_mu_has_labelled_mu_intercept_slope_q2()`; `has_phylo_mu_q2_covariance` and
  `split_tmb_corpars()` include Binomial (SD-formula fits only). Predict, the fitted SD
  output and marginal simulate needed no change: they already key on the provider's
  correlation key and read the fitted rho.
- Labelled Binomial `relmat()` and `spatial()` stay refused (not in this task's routes).

## 3a. Decisions and Rejected Alternatives

- Admitted only with two SD formulas. The no-SD labelled Binomial q2 would need the NB2
  `else` branch (estimated SDs with the correlation); not requested, so kept refused.
- Pedigree and `Ainv` inputs are admitted beside `A` because the C++ path is identical
  (precision from the provider); the test checks they reproduce the `A` fit.
- Phylo is logit only, matching the unlabelled phylo q2 gate. Probit and cloglog
  labelled phylo are refused with the existing message.
- The first phylo fixture (40 tips, 30 rows each, binary) put rho at the boundary and
  did not converge on 5 of 12 seeds. That is weak identification of rho in binary data,
  not a code fault; the fixture now uses 80 tips and 40 rows each, where fits converge and
  rho moves with the data. Not a tolerance change.

## 6. Tests of the Tests

Each fit asserts nine emulated bugs, each required to move the oracle by more than 0.1:
swapped SD selector coefficient sets, reversed SD vector for the intercept, reversed
SD vector for the slope, swapped intercept and slope SD vectors, kernel read by
position, kernel times 2, rho dropped to 0, rho sign flipped, and `cov2cor(K)`
(animal) or raw `ape::vcv` (phylo). Smallest gap over all routes: 0.167 (cloglog,
`cov2cor(K)`); the other minima are 0.38 (logit animal, `cov2cor(K)`), 1.67 (probit)
and 2.5 (phylo, rho dropped). The marginal-simulation check pools the per-group variance of the
simulated linear predictor against `K_gg (s0^2 + 2 rho s0 s1 x + x^2 s1^2)`; the observed ratios are 1.020
(animal) and 0.998 (phylo) against a 0.06 band, and the emulated rho 0, rho flipped
and (animal) `cov2cor(K)` diagonal give 1.67, 4.58 and a ratio outside the 0.10
margin. A test that `fit$corpars` holds the estimated correlation and moves with the
data: data with rho +0.6 and -0.6 give 0.74 and -0.65 (animal) and 0.70 and -0.84 (phylo).

## 8. Consistency Audit

Fit, `predict(dpar = ...)`, the fitted SD output (`coef`), `fit$corpars`, conditional
simulate (`re.form = NULL`) and marginal simulate (`re.form = NA`) all read the same
fitted rho and SD curves on the admitted routes. Unlabelled Binomial q2 fits are
unchanged: `has_phylo_mu_q2_covariance` stays 0 for them and the existing tests pass.

## 9. What Did Not Go Smoothly

- The first phylo fixture did not identify rho (section 3a).
- A first marginal-simulation check using the reversed intercept SD was too weak (pooled
  variance barely moves when the SD vector is permuted) and was dropped; the likelihood
  oracle covers that bug.
- Totoro was heavily loaded (load average about 300), so the existing Binomial files took
  tens of minutes; they were split across cores.

## 10. Known Residuals

Fixed-seed alignment and likelihood-assembly checks only. rho is weakly identified for
binary responses with few groups; no recovery, calibration, coverage or parity claim.
Labelled `relmat()` and `spatial()` Binomial blocks stay refused. The C++ change touches
the shared template (Binomial branch only, guarded by the data flag).

## 11. Team Learning

- When a route is refused in R, check the C++ branch before assuming a gate is the whole
  story: here the Binomial branch had no correlated prior at all.
- A binary-response rho needs 80 groups or more before the fixture is worth fitting.
- Split independent test files across the allotted cores; one serial `Rscript` was the
  slowest part.

## 12. Cross-Product Coverage

Covered: animal A (logit, probit, cloglog) and Ainv and pedigree (logit, equal to A),
phylo (logit); `mu:I` and `mu:x` SD formulas on separate non-palindromic predictors.
Not covered: relmat, spatial, mesh, non-logit phylo, no-SD labelled blocks, weights,
trials above one, REML, missing responses, interval calibration.

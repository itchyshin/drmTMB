# After-task: batch 26, Julia NB2 coordinate spatial slope-only SD and R bridge admission

Date: 2026-11-02. Lane: codex/general-sd-regression (R bridge); DRModels.jl worktree `general-sd-julia`, same branch name.

## What was asked

A Julia counterpart of native drmTMB NB2 `spatial(0 + x | site, coords)` with `sd(site, level = "spatial") ~ z`, mirroring the Gamma spatial slope route from batch 25, then R-bridge admission.

## Julia (DRModels.jl commit 87a371a66 on codex/general-sd-regression)

- `_drm_negbin2_sd_regression` accepts the spatial level with the slope-only marker. The kernel is the native fixed `exp(-d / median positive distance) + 1e-6 I` built from `coords`, entering RAW (not correlation-rescaled). A precomputed `K`, `A`, `Ainv`, a missing `coords`, a missing slope column and the spatial intercept form are refused.
- `predict`, `predict_parameters` and the bridge label renderer admit the spatial slope-only marker for NB2.
- New `test/test_nb2_spatial_slope_sd_regression.jl` (15 expectations): objective against an independently coded dense Laplace oracle (tolerance 2e-3); coords rows in the wrong order change the objective by more than 0.05 (kernel alignment is load-bearing); refusal pins. A correlation-rescaled kernel is nearly identical here because the kernel diagonal is 1 + 1e-6, so that check is only a sanity bound, not evidence of RAW scaling.
- Neighbour Julia tests re-run on Totoro (Julia 1.10.0) and passing: Gamma structured slope, NB2 relmat slope, NB2 animal slope, NB2 relmat intercept SD, NB2 SD refusals, hurdle NB2 SD, Gaussian relmat/spatial slope bridge.

## R bridge (this patch)

- `R/julia-bridge.R`: new gates `drm_julia_nbinom2_spatial_sd_slope_route_admitted` and `drm_julia_nbinom2_structured_sd_slope_route_admitted` (relmat or spatial). The three existing NB2 relmat gate call sites use the combined gate. In the structured payload the NB2 spatial slope is admitted (coefficient, term-type checks), and the coordinate kernel is converted to a relmat K exactly as for Gamma, so Julia runs its NB2 relmat slope route. The NB2 spatial intercept is still refused.
- `tests/testthat/test-julia-b25-gamma-nb2-slope-bridge.R`: the expectation that the NB2 spatial slope is refused was removed (it is now admitted).
- New `tests/testthat/test-julia-b26-nb2-spatial-slope-bridge.R`: gate, payload and refusal pins (non-live), plus one live native-vs-Julia check on a shuffled-row, named-coords fixture.

## Goal

`family = beta()` was resolving to `base::beta` and dying with `argument "a" is missing`. NEWS 0.7.1 also claimed `drmTMB::beta()` still worked. Keep `beta()` unexported. Make the failure name `beta_family()`.

## Repro (before the edit)

Installed drmTMB 0.7.1, R 4.6.0:

```
exports beta?: FALSE
drmTMB::beta() -> 'beta' is not an exported object from 'namespace:drmTMB'
family = beta() -> argument "a" is missing, with no default
family = beta_family() -> class drmTMB
```

## Implemented

`drmTMB()` and `impute_model()` evaluate `family` themselves. A bare `beta()`, `base::beta()`, or `stats::beta()` call, or `family = beta` as the Euler function, aborts with class `drmTMB_base_beta_family_error` and names `beta_family()`. `drmTMB::beta()` gets the same class and says it is not exported. `drmTMB:::beta()` still aliases `beta_family()` with the 0.7.1 deprecation warning.

`beta` is still not in NAMESPACE.

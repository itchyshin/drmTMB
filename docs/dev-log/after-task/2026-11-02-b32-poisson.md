# After-task report: batch 32, native Poisson labelled q2 SD (animal and spatial)

Date: 2026-11-02. Reader: Shinichi, and the next agent on the general-sd-regression lane.

## 1. Goal

Batch 31 found that native Poisson refuses `animal(1 + x | p | id, A = A)` and
`spatial(1 + x | p | id, coords = coords)` with one SD formula per coefficient.
Find why, and admit the routes if the C++ template already carries the prior.

## 2. Implemented

The C++ Poisson template already has the correlated q2 prior (`has_phylo_mu_q2_covariance`,
`rho = 0.999999 tanh(eta_cor_phylo)`, prior N(0, R kron K)); Poisson relmat labelled q2 uses it.
The refusal was only the R gate `allow_poisson_structured_q2_sd` in `R/drmTMB.R`
(`drm_build_poisson_spec`), which let a label through for relmat only; the labelled animal and
spatial terms then reached the one-coefficient parser and failed with "require one structured
coefficient". The gate now admits the label for `relmat`, `animal` and `spatial`. The
missing-response include clause for q2 animal gets `is.null(covariance_label)` so labelled
animal with `missing = "include"` stays refused (no evidence for it). No C++ change, no new helper
file. Provider mapping is unchanged: A or Ainv as supplied, native coordinate kernel for spatial.

## 6. Tests of the Tests

Emulated bugs against the oracle (all asserted above 0.1; smallest gaps animal 0.565 for
`cov2cor(A)`, spatial 4.6 for rho dropped): swapped SD formulas, reversed SD vector, rho 0, rho
sign flipped, cov2cor(A) (animal only; the spatial kernel diagonal is 1 + 1e-6 so it is not
testable there), kernel read by position. Kernel rows and coordinate rows are shuffled against the
data levels; SD predictors are continuous or three-valued and non-palindromic. The estimated
correlation moves with the data: rho_hat 0.67 vs -0.81 (animal) and 0.83 vs -0.24 (spatial) for true
+0.6 vs -0.6. Marginal `simulate(re.form = NA)` means match the analytic mean (pooled z2 1.2 and
0.9) and dropping rho is clearly worse (23 and 35).

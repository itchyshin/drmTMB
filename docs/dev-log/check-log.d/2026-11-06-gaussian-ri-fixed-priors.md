# Gaussian random-intercept fixed-effect priors (2026-11-06)

Closes #1680. This is a working evidence record; full-suite and 12-fixture cross-engine validation are pending.

The approved route is complete, unit-weight Gaussian ML with a single independent mean random intercept and fixed mean/log-residual-SD predictors. Normal and ridge priors target existing fixed-effect columns. The existing TMB prior term is independent of the random effect, so it enters the integrated likelihood once; no C++ change was made. Prior and data likelihood are separately reported. Unsupported random slopes, multiple groupings, scale or structured random effects, and existing inference restrictions remain fenced.

## Key decisions & rationale

1. **Bootstrap is scored by overlap, never endpoint equality.** `tools/parity_intervals.R`
   still compares endpoints, so all 14 bootstrap rows read `INTERVAL_MISMATCH` even though
   5 of 5 measured pairs OVERLAP. **Do not "fix" this by loosening the tolerance** — the
   test asks a question that cannot be answered yes. A written overlap patch exists.
2. **Three families were refused promotion**, each for a distinct measured reason (below).
   A row that does not clear the bar is not promoted with a caveat attached.
3. **`claim_status` deliberately untouched** (see Critical context).
4. **Cell ids use drmTMB `capability_id` spelling** (`fe_gamma`, not `gamma_fe`) so the two
   tables become joinable. Older ids (`poisson_fe`, `gauss_mean_only`) were deliberately
   NOT renamed — that would orphan banked rows.

## Gotchas / failed approaches — these cost the most time

1. **`Manifest.toml` is gitignored.** A fresh DRM.jl worktree CANNOT instantiate; every fit
   dies with `ForwardDiff ... Run Pkg.instantiate()`. Copy it from a working clone before the
   first fit. Four agents lost a run to this in one day.
2. **Verify the installed drmTMB before believing a refusal.** A build 273 commits stale
   silently refuses every family added since 0.7.0, and that refusal is indistinguishable from
   an engine limit. It produced two phantom "regressions".
3. **Regenerate the tip-identity receipt LAST.** It hashes every `R/*.R` plus 95 DRM.jl-side
   files. `receipt-staleness` went red on main three times on 2026-09-07 purely because three
   PRs touched `R/julia-bridge.R` in succession.
4. **A noisy `UndefVarError: loglogistic` / `LogExpFunctionsInverseFunctionsExt` line at Julia
   boot is MEASURED non-fatal.** Only treat a cell as failed if that cell produced no numbers.
5. **A grep miss is not proof of absence.** Cells appear both as `list(id = "x"` on one line
   and split across two; ids vary in case. Four confident wrong findings on 2026-09-07 came
   from naive greps — including a near-miss claim that 31 receipts were unreproducible, which
   was flatly untrue.
6. **A green suite that never called Julia is not parity evidence.** The source-tree lane
   prints ~24500 PASS and, in the same trailer, *"the LIVE ENGINE was not exercised in this
   configuration."*
7. **Bridge work is LOCAL ONLY.** Totoro's R segfaults embedding JuliaCall (measured).
   Native-R and native-Julia suites may go to Totoro; anything `engine = "julia"` may not.
8. Never read a main checkout's working tree as source truth (`git show origin/main:<path>`);
   ~30 worktrees share it. Never `git stash` in these repos — one shared stash stack.
9. The R fitting function is **`drmTMB()`**; `drm()` is the Julia-side name.

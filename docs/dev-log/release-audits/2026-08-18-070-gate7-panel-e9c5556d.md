The branch repair aligns README, NEWS, DESCRIPTION, the introductory vignette,
the formula guide, the capability guide, and the pkgdown banner with 0.7.0.
The six plot-heavy or detailed reader pages move to `vignettes/articles/`, so
pkgdown renders them while `R CMD build` does not compile or install them. A
final repaired-tree probe produced a 4,367,966-byte source tarball and reduced
installed documentation to 4.7 MB. The unverified cheatsheet PNG was removed
from the current tree and remains recoverable from Git history.
`inst/COPYRIGHTS` records the logo's repository history, authorship, content,
and package licence.

`tests/testthat/test-release-identity.R` now fails when DESCRIPTION, README,
NEWS, the introductory vignette, formula guide, or pkgdown banner drift from
one another, and it preserves the development-article boundary and PNG absence.
The package's
existing CRAN filter already excludes the expensive association-validation
suites while retaining them under `NOT_CRAN=true`; a source-mode timing probe
that ignored this filter was stopped after exceeding its estimate and did not
justify further test suppression.

## Findings

### 1. Duplicated logo assets — 196 KB of dead weight

`man/figures/logo.png` is **byte-identical** to `man/figures/drmTMB-logo.png`
(`c0928241…` both), and `logo.svg` to `drmTMB-logo.svg` (`2a531880…` both).

Nothing references the `logo.*` pair: `README.md:1` and `_pkgdown.yml:14` both point at
`drmTMB-logo.png`. So 196 KB ships twice for no reader benefit.

**Caution before deleting.** `man/figures/logo.png` is the conventional path
`usethis::use_logo()` creates and that pkgdown auto-detects. `_pkgdown.yml` sets the logo
explicitly, so the duplicate is *probably* redundant — but Stage B must **rebuild the site
and confirm the logo still renders** before dropping it. Not a rights issue; an
installed-size and tidiness one. Recorded, not applied.

### 2. Author-role consent

`DESCRIPTION:3-7` lists exactly one person: Shinichi Nakagawa, `aut`/`cre`/`cph`, ORCID
`0000-0002-7765-5182`. The maintainer is the sole author and copyright holder, so there is
no third-party consent to collect.

**Still owed before upload:** an explicit, dated author-role consent line, per the
protocol's Gate 1. Trivial here, but it is a required row and Stage A does not fabricate it.

### 3. Exclusions are declared but **not proved**

Everything in the ship/exclude column above is read from `.Rbuildignore` and directory
listings. The protocol is explicit that exclusions must be proved **by listing the built
tarball**, not by pointing at `.Rbuildignore`.

Stage A builds no tarball (owner decision, 2026-08-09), so this proof is **owed in Stage B**.
The predecessor 922-path inventory is a useful *expectation* — it showed `docs/`, `tools/`,
`AGENTS.md`, `CLAUDE.md`, scratch, pkgdown-site, and VCS paths correctly absent — but it
describes a superseded artifact and is not the candidate's proof.

Of note for the size budget: `inst/sim` (1.9 M), `inst/trust-dossier` (152 K), and
`inst/dg3-power-arm` (60 K) **do** ship. That is ~2.1 MB of harness and dossier material in
the installed package, and it is a deliberate choice, not an oversight — the predecessor
freeze recorded `sim` at 1.9 MB in its 31.2 MB installed footprint. Flagging it because
installed size is already a known NOTE surface; whether that material must ship is a
question worth answering once, deliberately, rather than inheriting.

### 4. `inst/CITATION` fallback version

`inst/CITATION` falls back to `"0.1.4"` when `meta$Version` is unavailable. Cosmetic, and
in a normal install `meta$Version` resolves — but a stale hard-coded version in the citation
a user will paste into a paper is worth correcting in the same Stage B pass.

## Rights verdict

**No blocking rights defect.** Licence is coherent (GPL (>= 3) throughout, both adaptations
GPL-3), provenance is recorded where it should be, and there are no shipped datasets or
third-party assets.

**Not yet closable.** Gate 1 cannot be marked complete until Stage B (a) proves exclusions
against the built tarball, (b) records the dated author-role consent line, and (c) confirms
or corrects the logo-duplicate decision against a rebuilt site.

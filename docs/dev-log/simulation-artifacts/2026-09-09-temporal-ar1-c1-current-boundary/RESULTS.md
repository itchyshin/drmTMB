# Current-source C1 dense marginal profile

This profile independently marginalizes the ordinary intercept and AR1 field through `s_b^2 11^T + s_a^2 R(phi) + sigma^2 I`, profiles the three mean coefficients by GLS, and optimizes the remaining variance and persistence coordinates. It is a fixed-seed diagnostic, not a coverage campaign.

The grid and four signed persistence starts match the earlier C1 dense diagnostic. It determines whether the current-source unavailable covariance case has likelihood geometry that reaches the residual-variance boundary.

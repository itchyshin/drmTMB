# Step 1: Poisson animal q2 with two coefficient SDs, R versus Julia

One simulated dataset (G = 48 animals, m = 24 rows each, 1152 rows), fitted in native R drmTMB (clean `origin/main` worktree, temporary library) and in DRModels.jl branch `claude/poisson-animal-q2-sd-20261107` (commit `b6f10b4ee`, unpushed). Julia now fits `y ~ x + animal(1 + x | g)` with `sd(g, animal, coef(intercept)) ~ z0` and `sd(g, animal, coef(x)) ~ z1`; before this commit it threw an ArgumentError.

| Quantity | Julia minus R |
| --- | --- |
| Fixed effects, max absolute difference | 3.1e-8 (4e-7 SE) |
| SD-regression coefficients (4), max absolute difference | 3.7e-7 (1.6e-6 SE) |
| Log-likelihood | 6.9e-11 (both -1786.0236) |
| SE ratio | 0.999999 to 1.000000 |

Both fits converged. This is one dataset and one seed, so it shows the two implementations compute the same likelihood optimum here; it is not a coverage or recovery study. The data and A matrix are regenerated by `fixture.jl` (not stored).

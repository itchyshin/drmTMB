## Step 2. R's REML definition (from `drm_apply_estimator_spec` and the C++)

`spec$tmb_random_names <- c(random_names, "beta_mu")` (plus `beta_sigma` only when a sigma variance component exists). TMB's Laplace step over `beta_mu` is exact for a Gaussian, so the restricted log-likelihood is

    l_R(theta) = log N(y | X b_GLS, V) + (p/2) log(2 pi) - (1/2) log |X' V^-1 X|

including the `(p/2) log 2 pi` constant (the same constant Julia's other REML routes use, DRM.jl #477). Confirmed numerically: the Julia value equals R's `logLik` to 8e-10 on every cell below.

## Step 3. Julia implementation

`src/gaussian_lss.jl`, `_fit_structured_gaussian_q2_sd`: `nll_reml = nll_ml + 0.5 logdet(X' V^-1 X) - 0.5 p log 2 pi`; the optimiser works on the variance parameters only with `beta_mu` profiled out by GLS (as TMB does once `beta_mu` is integrated), then finishes on the full vector so `theta`, `vcov`, blocks and `reml_loglik` / `ml_loglik` have the usual shape. The router gate mirrors R: any `phylo` cell; `animal`/`relmat`/`spatial` only unlabelled with `sigma ~ 1`; full-rank `mu` design.

A first version carried `beta_mu` as a free coordinate (the pattern the other Julia REML routes use). On one fixture (relmat, seed 4) it stopped at a REML optimum 5.13 log-lik units below R's (R -410.8485139; Julia -415.9811017; Julia's own objective at R's theta reproduces R's value to 4e-10, so the objective was right and the optimiser was not). Profiling `beta_mu` fixed it: Julia then lands on R's optimum (theta equal to 4 d.p.). A multi-start was tried first and did not help, so it was dropped.

## Step 4. R versus Julia at the optimum (6 cells x 5 seeds, REML and ML)

Data are generated by `r_run.R` (G = 40 groups x 12 rows = 480 rows; seeded; stored in `data/`), fitted by R (`r/`) and by Julia (`julia/`, `julia_run.jl`); `compare.R` writes `summary.csv` (one row per cell) and `parameters.csv` (per parameter). Cells: animal, relmat, phylo, spatial (unlabelled, `sigma ~ 1`), phylo labelled (rho = 0.5 in the data), phylo with `sigma ~ x`. Seed 1 is the single-dataset case; seeds 1-5 are the table.

REML, 30 fits (all converged in both languages, R pdHess TRUE in all):

| Quantity | Worst case over the 30 REML cells |
| --- | --- |
| max abs coefficient difference (mu, sigma, SD formula coefficients, eta_rho) | 9.3e-8 |
| max abs difference in the natural-scale SDs at z = 0 (exp of the SD intercept coefficients) | 7.6e-11 |
| abs difference in rho (labelled cells) | 2.8e-11 |
| REML log-likelihood, Julia minus R | within 8.1e-10 |
| max relative SE difference (all coefficients) | 2.0e-5 |
| max relative SE difference, mean block only | 1.1e-5 |

The SE agreement is closer than the 1.5e-3 mean-block gap recorded for the sparse phylo-mean REML route (doc 261), because here Julia's `vcov` is the inverse Hessian of the restricted objective over the full vector, which carries the same variance-parameter uncertainty as R's `sdreport`.

ML (reference only, the same 30 cells): 29 of 30 agree at the same precision. One does not: relmat seed 1 ML, where R's `logLik` is -402.4469 and Julia's is -398.8762 (Julia higher by 3.57, both reported converged). This is the same kind of outer bimodality documented in `wave4-gamma-crossed-diagnosis`; REML for the same dataset agrees to 1e-10. Not touched here.

## Honest gaps

- Structured sigma REML (`sigma ~ 1 + animal|relmat|phylo|spatial(1 | g)`): native R fits it, but it integrates `beta_sigma` as well as `beta_mu` by Laplace (the sigma coefficients enter non-linearly), which is not the Gaussian-mean-only restriction asked for here. Julia still refuses it. Not implemented.
- Ordinary q2/q3/q4 and joint mu + sigma `sd()` REML: R refuses, so Julia keeps refusing (nothing to match).
- The R-to-Julia bridge (`engine = "julia"`, drmTMB `drm_julia_reml_supported()`) was not changed; it presumably still withholds REML for these shapes. This lane only changed DRModels.jl.
- `animal(1 + x | g)` with `sigma ~ x` and labelled non-phylo blocks refuse under REML, as in R; Julia's ML fits them.
- Dense n x n marginal, so n <= 5000 as for the ML route. Labelled phylo REML takes about 15 s at n = 480.
- Mean-coefficient Wald intervals for REML: not examined; R documents none.

## Public page contract

The first reader-facing summary separates:

1. Can I fit it?
2. Can I report the point estimate?
3. Can I report the named interval?
4. If not, what exact simpler model or tool should I try?
5. What is the exact tested scope?

Internal cell IDs, q labels, Arc names, and campaign mechanics stay below the fold under **Evidence and exact tested scopes**. Define `mu`, `sigma`, `nu`, `rho12`, `sd(group)`, `phylo()`, `spatial()`, and `meta_V(V = V)` at first use. `meta_known_V()` appears only as a deprecated alias; `tau` remains restricted.

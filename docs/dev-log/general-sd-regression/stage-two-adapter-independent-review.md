# Optional second-look adapter: independent source review

**Verdict, 2026-10-17: NO-GO for preparation or launch with this source snapshot.** The pure Python tests pass and the Python/R raw-attempt digest agrees, but two deterministic defects prevent a healthy combination, and the prelaunch gate does not independently recompute the first-look decision from its raw attempts and original RDS. Repair and exercise these conditions before a three-case adapter qualification. This review inspected source only; it did not prepare a stage-two capsule or run a model fit.

The reviewed files were `stage_two.py` SHA-256 `dca9ebf2c1f5e9ae7ca0a9df328d6f99e6107d1ea642467e713fc22392b85978`, `prepare-stage-two.py` `1fca9a9db3353d8f1ff0142ef2c6597c67cfd0b514a0ea171f4596f7129bea2a`, `run-stage-two.py` `1c552ae0625796518453f0147ca5ace09e38e53df5f5394ce26d34550124d88e`, `combine-stage-two.R` `346ec8ae04f8689d757e32282e67d70127956fc05e680bfb8558572b3d8ee516`, and `test_stage_two.py` `9cd3fee6646c2f78364e84555e84f86716a59f6529cb80a9bf0c044deeef1373`. Later edits require a new readback.

The `run_batches()` outer timer starts after its preflight and does not include the separate combination program (`stage_two.py:211-239`). Its per-batch cap is bounded by the remaining time, so the worker run itself is capped, but the design's claimed 10,500-second end-to-end bound needs one parent supervisor or an explicit accounting of preflight/combination and cleanup. Do not infer an all-attempt campaign decision from the static `root-preparation-receipt.json` field `no_fits_launched=TRUE`: after execution it remains a provenance statement about preparation, not a current status. The combiner does require 12,000 rows and 4,000 per truth (`combine-stage-two.R:107-111`) and converts missing error/timeout result rows to invalid attempts. If the frozen analyzer ever returns `integrity_failure` or `incomplete`, the combiner currently still writes `STAGE_TWO_COMBINE_COMPLETE`; make its process status and receipt nonqualifying rather than relying on readers to notice the decision field.

**Positive source checks:** `python3 tools/general-sd-regression/native-calibration-stage-two/test_stage_two.py` passed six pure tests; Python compilation and R parse passed. For the retained first-look attempt capsule, the Python and R implementations both produced SHA-256 `873938d89ee1564272a29f83a27cf0ee7ef11e64b4848f0f105c19f7c7f9178c` from the ordered manifest, supervisor and 3,000 result files. In a temporary copy, changing one result byte or deleting one result changed the Python digest. A small `jsonlite::fromJSON(..., simplifyVector=TRUE)` fixture confirmed that the root `batches` array becomes a data frame and numeric-string JSON map keys remain named list entries, so the current root/batch map comparison is coherent. These checks establish only those mechanisms; none exercises preparation, supervisor failure, complete combination, or model fitting.

**Required next receipt:** After repair, retain source hashes, run pure negative controls for each blocker, then qualify the adapter on three separately sealed cases using the exact original Bernoulli source/library. Verify first-look RDS replay before any worker starts, all child processes reaped, batch and root seals, raw attempt digests, correct stage-two source-row mapping, and the 12,000 planned denominator under both valid and terminal-invalid fixtures. Only a clean qualification plus the measured under-three-hour calculation supports a later recorded GO under the already approved programme.

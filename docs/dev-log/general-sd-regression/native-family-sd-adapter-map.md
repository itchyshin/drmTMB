# Native family adapter map for ordinary `mu` SD regression

This is a source map for choosing the next native-family implementation slice. It describes the current worktree's implementation hooks; the fit evidence and inference grade are stated separately for each family. The direct ordinary `mu` SD route currently has family-specific admission: Gaussian, binomial, Poisson, zero-inflated Poisson, lognormal, complete-data NB2, zero-inflated NB2, zero-truncated NB2, hurdle NB2, Gamma, Tweedie, Beta, beta-binomial, cumulative-logit, zero-one beta, Student-t, and skew-normal builders construct a populated `random_scale$mu`; the other builders listed below return an empty structure or reject the formula. R-side metadata is therefore only one part of the route.

## Existing path and family differences

The reusable R pieces are the SD structure constructor `build_sd_mu_structure()` (`R/drmTMB.R:17386-17440`), family target resolvers, and the common start/map/extraction machinery. Gaussian builds the structure at `R/drmTMB.R:4470`, stores it in its spec at `:4636`, and now admits one ordinary independent numeric location slope; its focused native recovery, simulation, constant-SD, and same-data Julia parity checks are recorded in the after-task report. Binomial resolves eligible terms and builds it at `R/drmTMB.R:7826-7830`, then includes it in its spec/start/map at `:7851-7885`; Poisson does likewise at `:8498-8499` and `:8531-8602`. Lognormal resolves ordinary `mu` intercepts and one independent numeric slope; Gamma resolves ordinary intercepts; Student-t resolves ordinary intercepts and one independent numeric slope; Beta and skew-normal resolve ordinary `mu` intercept and one independent numeric slope SD design; beta-binomial resolves one independent numeric slope SD target. Tweedie resolves intercept and one independent numeric slope SD design through the shared start, map, extraction, and prediction paths. Separate structured routes include Gamma's q1 animal intercept and slope-only targets. Beta keeps its ordinary and phylogenetic direct-SD routes separate; beta-binomial is complete-data only in this slice.

## Minimal reusable adapter

The lowest-risk shared unit is a small C++ helper that evaluates `X_sd_mu * beta_sd_mu`, applies the existing soft clamp and guarded exponentiation, and returns per-group SDs. Each model branch should retain its own predictor scale, likelihood, and ordinary-effect geometry, while its existing `mu_re_sd_row` selects the group SD for an effect (`src/drmTMB.cpp:364-367` declares the common data/flag; R's generic structure assigns rows in `R/drmTMB.R:17386-17440`). This avoids a shared likelihood abstraction and leaves family-specific correlated blocks intact. Lognormal, NB2, and Student-t intercept routes, plus tested selected independent slopes in lognormal, Student-t, zero-inflated NB2, zero-truncated NB2, and hurdle NB2, exercise this mapping. This map is limited to ordinary `mu` routes; it does not establish completeness across structured providers, other distributional endpoints, bivariate blocks, or Julia.

Every family slice also needs builder admission/target checks, starts/maps and `get_tmb_data()` flag wiring, and output/report alignment. Common extraction already keys off `model$random_scale` (`R/drmTMB.R:23323-23379; `R/methods.R:6757-6808`), while profile metadata has a generic direct-SD check (`R/profile.R:4545-4558`). Still audit family-specific coefficient/summary categorization in `R/methods.R` and simulation/bootstrap admission before claiming downstream parity. Existing constant-SD ordinary random-effect tests provide base-route fixtures, not SD-regression validation.

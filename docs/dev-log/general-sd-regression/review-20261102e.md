## What this batch did

Before this batch, 152 of the 354 linked ledger rows had receipts but no reviewed evidence. Five agents worked in parallel on them, one per group: native Binomial, native other families, Julia Binomial correlated blocks and animal routes, Julia Binomial other routes, and Julia other families. Each wrote new test files only, every one with an oracle that shares no code with the package and with emulated-bug checks asserted far above tolerance. Each then produced receipts. Every group was then reviewed by an independent reviewer and checked by a skeptical verifier.

Result: 23 new test files with receipts. Rows with reviewed evidence rose from 202 to 331 of 354. Reviewed evidence ids: 101. Reconciler: `EVIDENCE_RECONCILIATION_PASS candidate_rows=21246 linked_rows=354 unlinked_rows=20892 evidence_records=765`.

## Decisions applied in the merge

- An id is granted only when the reviewer granted it and the verifier confirmed it. A row that either of them marked as not exercised is not linked.
- Correlated-block rows require an estimated shared correlation. Two files fitted unlabelled native blocks, where the correlation is structurally zero; native refuses the labelled form for those routes. Their 18 rows are not linked: Binomial animal and phylo, Poisson animal and spatial, NB2 phylo, and Gamma relmat and phylo. The Julia Binomial animal q2 file does estimate the correlation and is granted. An audit of earlier grants found no correlated-block row fitted without an estimated correlation.
- Slope-only fits. Reviewers and verifiers objected to slope-only fits linked to rows that describe an intercept plus an independent slope. This lane's rule (review-20261102.md) is that an unlabelled structured `(1 + x | id)` is two independent fields, so a slope-only fit supports the slope-member SD row if the note says slope member only. The rule was applied consistently. The objections are recorded in the receipts (`verifier_objection` on `julia-binomial-animal-slope-oracle-b31ja-20261102e`) so the rule can be revisited.
- Julia quadrature accuracy. Julia's scalar iid routes integrate with Gauss-Hermite rules. Against an exact integral they are off by 1e-3 to 1e-2 for most families, up to 3.07 for ZeroOneBeta and 0.12 for the zero-inflated Poisson slope. The fixtures for the affected files were chosen from a six-seed pre-scan, and those grants are scoped to likelihood assembly and selector alignment at the fixture. The ZeroOneBeta iid rows and the zero-inflated Poisson iid slope row are not linked. The finding is in `docs/dev-log/known-limitations.md`.
- The Binomial iid correlated Julia route uses 5-node adaptive quadrature per axis. Its oracle reimplements that scheme independently, agreeing to 1e-13, and the receipts say this is not the exact marginal: the 15-node value sits 0.009 to 0.082 away.

## DRModels.jl follow-ups landed in this batch

- `2c32dd535`: the coupled location-scale `(1 | tag | relmat(g))` engine (Beta, beta-binomial, NB2, Gamma) now uses relmat and animal K as supplied, as native does. A new test with a non-unit-diagonal K and an independent dense Laplace oracle passes, and it fails 12 of 20 on the previous source. Gaussian Julia routes already used raw K and needed no change.
- `e7dbc3f79`: the Beta animal `sd(g) ~ z` fit could stop about 0.95 to 3.4 log-likelihood units short of the optimum while reporting convergence. The inner Laplace mode search stopped with gradient near 1e-6, above the route's own cutoff, so a finite-difference stencil point returned the failure sentinel; the outer optimiser then took a zero step and reported x-convergence. It reproduced in 15 of 40 fits under 1e-12 data perturbations, in both the worktree and a freshly resolved environment, so it is not tied to one package version. A Newton polish of the inner mode (no tolerance changed) removes it: 0 of 80 perturbed fits stop short. The drmTMB live Beta and ZeroOneBeta parity file passes 27/0. This resolves the environment sensitivity recorded in review-20261102c.md.
- Open: the same pattern, an inner-mode failure sentinel feeding a finite-difference outer gradient, may exist in other structured Julia SD routes (Gamma, NB2, Poisson animal SD). Not yet checked. The recommendation is not to commit a `Manifest.toml` to DRModels.jl, because a committed manifest would hide this class of bug from users who resolve dependencies afresh.

These frozen data and expected values are copied byte for byte from the independently authored MIT-licensed oracle in `tools/ranef-sd-prior-oracle/oracle/`. The copies and licence ship with package tests because `tools/` is excluded from the R source package. Verify them with `shasum -a 256 -c SHA256SUMS` from this directory. The tests use jsonlite and numDeriv from Suggests; set `DRM_SD_ORACLE` to override the default fixture directory. See the full oracle README and original manifest in the repository for provenance and numerical conventions.
